## Was war das Problem?

**Decorator-in-Loop Antipattern:**

```python

    @_sensor_circuit_breaker    # NEU bei jedem Durchlauf!

```

**Auswirkung:**
- Circuit Breaker wurde bei JEDEM Loop-Durchlauf neu erstellt
- Fail-Counter nie akkumuliert
- Circuit konnte nie "trippen"

## Die Lösung (v6.23.1)

```python
def _direct_sensor_read():      # EINMAL definiert
    return sensor.read()

```

**Änderungen:**
1. `_direct_sensor_read()` Funktion AUSSERHALB der Schleife
2. `.call()` Methode statt Decorator
3. Circuit Breaker Singleton wird wiederverwendet
